# Runner 利用ガイド（利用者向け）

## 画面構成

1. **★ お気に入り** — よく使うアプリ（サムネ + 名前 + リポジトリ名）
2. **最近使った** — 起動履歴
3. **＋ 他のアプリを検索** — 公開リポジトリのモーダル検索（サムネ付き）

## サムネイル

- Creator で保存した `nora/assets/thumbnail.png` が Runner に表示されます。
- サムネが無い場合は 📦 プレースホルダです。

## 最新版への更新

開発者が Gitea に新しい版を公開すると、サーバー側 artifact の `artifactSha` が変わります。

- お気に入り登録後、ローカルに古い展開済み環境があると **●** とオレンジ枠で表示されます。
- 画面上部に「最新の公開版があります」バナーが出ます。
- **最新版** / **ワンクリックで最新版に差し替え** で、ローカルの Runner 環境フォルダを丸ごと新しい zip に置き換えます（コードと venv 展開先を一体として更新）。

## 整理（ストレージ）

`runner-apps` 配下のキャッシュ削除。お気に入りは `runner-app-prefs.json` に残ります。
