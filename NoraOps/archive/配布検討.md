# NoraOps「配布」の二層（用語の整理）

**「配布」という語が指す対象が二つあります。** 同じ単語でも **誰が受け取るか** が違うので、資料では次の呼び分けを使います。

| 呼び名 | 受け取る人 | 何を載せるか | Gitea に例えると |
|--------|------------|--------------|-------------------|
| **プラットフォーム提供**（サーバ側） | **組織の管理者**（運用／インフラ） | **同一マシン上**に **Gitea と FastAPI を載せ・起動**するまで。**Docker を前提とはしない**。 | **Gitea をサーバに入れる／初回セットアップ** |
| **クライアント提供**（利用者側） | **各開発者・利用者** | VS Code **拡張（.vsix）** — **Creator**（開発）+ **Runner**（承認済みアプリの検索・実行）。将来 **Tauri** は Runner のみ。 | **開発者 PC のクライアント** |

プラットフォームの **標準ゴール**：**統合インストーラ（ウィザード）** → **Gitea 導入** → **FastAPI の導入と自動起動**が **一台のハード**上で終わり、管理者が **ホスト名・ポート・外向け公開**などを設定して運用開始。詳細フェーズは [フェーズ進行.md](./フェーズ進行.md) の **〇 / MP1 / MP2**。

---

## A. プラットフォーム提供（管理者向け・単一ホスト）

**Docker Compose を唯一の公式ルートとはしない**。開発者が任意で使うのは構わないが、**組織向けのナラティブな体験**はネイティブ／統合 exe を想定する。

### A.1 提供形態の候補

| 方式 | 想定環境 | 備考 |
|------|----------|------|
| **統合セットアップ exe（推奨の北極星）** | Windows Server / オンプレ PC | Inno / NSIS 等。組み込みまたはバンドル：**Gitea バイナリ配置**、`app.ini` 生成、**埋め込み Python or 明示ランタイム**で FastAPI、**Windows サービス登録**。 |
| **ZIP＋セットアップ ps1**（MP1 で可） | インストーラ前段 | 「単一ホスト手順」をスクリプト化。_exe への肉付け前の現実解。 |
| ~~Docker のみ公式~~ | （任意・付録） | コンテナ運用組織向け。**メインストーリーから外す**。 |
| **Kubernetes / Helm** | 大規模 | 別系。単一ホスト版と要件が分岐。 |

### A.2 ウィザードで聞く項目（案）

1. **データディレクトリ**（Gitea / NoraOps 共通ルートまたは分離パス）
2. **外向け URL** と **ホスト名**（証明書・リバースプロキシのヒントのみでも可）
3. **ポート**（Gitea HTTP／FastAPI）
4. **Windows サービス**として自動起動するか
5. **初回管理者**（FastAPI と Gitea の連携トークンの生成ウィザード内で案内）

### A.3 プラットフォーム提供物に含めるドキュメント

- アップグレード・バックアップ一覧
- 「**クライアント利用者向け URL**」（承認済みカタログの前提が書かれたページ）へのリンク

## B. クライアント提供（各ユーザーの手に渡す拡張・ツール）

### B.1 前提：検索ヒットは **承認済み** のみ

- **Runner**（拡張内 / 将来 Tauri）の検索結果は **`/catalog/published`（等）のみ** を参照。**Gitea 全アプリ自動列挙ではない**。詳細は [フェーズ進行.md](./フェーズ進行.md)・[ポータルとクライアント.md](./ポータルとクライアント.md)。

### B.2 配布チャネル

| もの | 置き場 | 備考 |
|------|--------|------|
| **.vsix** | ② が静的配布 | **M1** |
| **Tauri exe（将来）** | 同上または社内 SCCM | Runner 専用・軽量（Phase2+） |
| **uv / Portable Git** | `GET /api/tools/...` | ワークステーション用 |

|----|------|

---

## D. まとめ

- **プラットフォーム**：**単一ホスト・統合インストーラ**志向。**コンテナ優先にはしない**。  
- **クライアント**：**FastAPI が承認したリポ×バージョンだけ**検索ヒット。**疎取得＋uv** は ③ で実現。
