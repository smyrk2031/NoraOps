# NoraOps 共有ツール（uv / git）— 配置場所

**方針**: **正本は FastAPI サーバ 1 か所**（`data/tools`）。各 PC はそこからコピーする。  
**sha256 の入れ方（手順）**: [manifest-jsonの書き方.md](./manifest-jsonの書き方.md)

---

## 0. インストール先まとめ（2か所）

| 層 | uv | git |
|----|-----|-----|
| **サーバ正本**（資産管理） | `data\tools\uv\<ver>\uv.exe` | `data\tools\git\<ver>\PortableGit-….7z.exe` |
| **各 PC**（削除可） | `%LOCALAPPDATA%\NoraOps\runtime\tools\uv\uv.exe` | `…\runtime\tools\portable-git\cmd\git.exe` |

PC だけ消す: `Remove-Item -Recurse -Force $env:LOCALAPPDATA\NoraOps\runtime`

---

## 1. サーバ側（手動配置・あなたが置く場所）

リポジトリ基準（`softrail-server` フォルダ内）:

| ツール | 配置パス（必須） | 公式ダウンロード元 |
|--------|------------------|-------------------|
| **uv** | `data\tools\uv\0.6.0\uv.exe` | https://github.com/astral-sh/uv/releases → `uv-x86_64-pc-windows-msvc.zip` 展開の **uv.exe のみ** |
| **Portable Git** | `data\tools\git\2.54.0\PortableGit-2.54.0-64-bit.7z.exe` | https://github.com/git-for-windows/git-snapshots/releases |

絶対パス例:

```text
nora-backend\data\tools\uv\0.6.0\uv.exe
nora-backend\data\tools\git\2.54.0\PortableGit-2.54.0-64-bit.7z.exe
```

### 配置後の確認（PowerShell）

```powershell
# 200 になること
Invoke-WebRequest -Uri "http://127.0.0.1:8000/api/tools/files/uv/0.6.0/uv.exe" -Method Head
Invoke-WebRequest -Uri "http://127.0.0.1:8000/api/tools/files/git/2.54.0/PortableGit-2.54.0-64-bit.7z.exe" -Method Head
```

### manifest の更新（脆弱性対応・バージョンアップ時）

編集ファイル: `softrail-server\data\tools\windows-x64\manifest.json`

**sha256** = その `url` のファイル全体の SHA-256（配置後に実測。ダミー不可）。詳細は [配布物管理.md §5](../softrail-server/docs/配布物管理.md)。

```powershell
(Get-FileHash -Path "data\tools\uv\0.6.0\uv.exe" -Algorithm SHA256).Hash.ToLower()
(Get-Item "data\tools\uv\0.6.0\uv.exe").Length
```

新バージョンは **新フォルダ**に置き、manifest の `version` / `url` / `sha256` / `size` を切り替える。

## 2. クライアント側（拡張が自動で置く場所）

| ツール | パス |
|--------|------|
| uv | `%LOCALAPPDATA%\NoraOps\runtime\tools\uv\uv.exe` |
| git | `%LOCALAPPDATA%\NoraOps\runtime\tools\portable-git\cmd\git.exe` |
| 状態 | `%LOCALAPPDATA%\NoraOps\runtime\tools\tools-state.json` |

導入コマンド: VS Code → **NoraOps: ツールをセットアップ（uv / git）**

---

## 3. バージョン後進（脆弱性対応）

1. サーバに新 `uv.exe` / PortableGit を配置  
2. `manifest.json` の version・sha256・`forceMinimum*` を更新  
3. ユーザーは拡張で **ツールをセットアップ** を再実行 → 新 manifest と照合し、古ければ再 DL  

拡張は起動時 **自動 DL しない**（明示コマンド or 保存前の軽い通知のみ）。
