📦 取り込む ZIP の作り方

Runner は Python アプリを丸ごと ZIP にしたものを取り込みます。Gitea もサーバーも不要で、オフラインでも動きます。いちばん簡単なのは Creator の「保存」で作った ZIP をそのまま使うことです。

1. フォルダの中身（最低限これだけ）

あなたのアプリ/
├─ pyproject.toml        ← 依存パッケージの定義（必須）
├─ nora/
│   └─ manifest.json     ← どのファイルで起動するか（必須）
├─ main.py               ← 実際のプログラム（例）
└─ README.md             ← 説明（任意・あると親切）

※ フォルダ名は自由です。この「あなたのアプリ」フォルダの中身を ZIP にします（フォルダごと ZIP でも、中身だけ ZIP でも取り込めます）。

2. pyproject.toml の例

[project]
name = "my-app"
version = "0.1.0"
requires-python = ">=3.11"
dependencies = [
    "flet==0.85.3",
]

使っているライブラリを dependencies に並べます。Runner はこれを見て uv で自動的に環境を作ります。uv.lock があれば一緒に入れると再現性が上がります。

3. nora/manifest.json の例

起動ファイルを 1 つ指定します。どちらかの書き方で OK です。

// ① スクリプトを直接起動する場合
{
  "entry": "main.py"
}
// ② モジュールとして起動する場合（python -m ...）
{
  "entryKind": "module",
  "entryModule": "gemini_twin.app.main"
}

4. ZIP に入れてはいけないもの

  • .env / .env.*（パスワード・APIキー）
  • .venv / venv（仮想環境。Runner が作り直します）
  • .git / __pycache__ などの作業ゴミ
  • *.pem / *.key / *.p12（秘密鍵）

これらが含まれていると取り込み時にエラーで止まります（安全のため）。取り除いてから ZIP を作り直してください。

5. サムネイル（任意）

nora/assets/thumbnail.png を入れておくと、Runner のタイルにアイコンとして表示されます。

6. Windows での ZIP の作り方

  1. アプリのフォルダを開く
  2. 中身を全選択 → 右クリック → 「送る」→「圧縮 (ZIP) フォルダー」
  3. できた .zip を「📦 ZIP から追加」で選ぶ
迷ったら: Creator でアプリを作って「保存」すると、ここで説明したルールどおりの ZIP が自動で作られます。それを取り込むのが確実です。
