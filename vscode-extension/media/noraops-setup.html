ログイン後に一覧を取得できます

ポータル URL

ブラウザで NoraOps のトップが開けるアドレスを入力し、接続テスト → 保存してください。

環境構築（uv）

Python 仮想環境の作成に使う uv をセットアップします。閉域ネットワークでプロキシ経由のダウンロードが必要な場合は URL を入力してください（Creator / Runner の uv sync にも使います）。

ネットワーク

この PC の接続情報と、NoraOps サーバーへの到達性を確認します。閉域ネットワークではインターネット不可でも問題ありません。

セキュリティガード

IP・パスワード・APIキー・個人情報などの直書きを検出します。フォルダ構成チェックは含みません。ルールごとにテスト入力で判定を確認できます。

アカウント登録

メールアドレスを登録し、届いた URL で本登録すると NoraAccessToken が表示されます。トークンを下の欄に貼り付けてください。

Gitea 登録が途中で止まっている場合、管理者が GITEA_TOKEN を修正したあとに再試行できます。

トークンを紛失した場合は、登録メールアドレスで再発行できます。
