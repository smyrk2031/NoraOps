運用メモ

  • 作成後、VS Code 拡張の Setting → アカウントにトークンを貼り付けます。
  • トークン再発行は一覧の「トークン再発行」から。旧トークンは失効します。
  • Gitea 登録が途中で止まった場合は「Gitea 再試行」を利用してください。
  • NORAOPS_ADMIN_MANUAL_PROVISION=0 にすると UI/API は停止しますが、データは残ります。
  • 削除は Gitea にリポジトリが残っていると失敗することがあります。
